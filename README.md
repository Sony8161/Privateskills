# Privateskills

Claude Code skills for building a product end to end. Copy the folders into `~/.claude/skills/`.

Start with `forge` (the workflow) and `security` (threat model, static review, authorized pen test).
It also chains in `intent`, `brief`, `swarm`, `verify`, `bay`, `code-quality` and `agent-evals`,
and expects these companion skills to exist: `spec`, `decide`, `pressure-test`, `investigate`, `ship`, `retro`, `grc`, `meeting-prep`.
